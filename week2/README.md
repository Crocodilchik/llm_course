# Неделя 2 — инструменты, агент и веб-MVP

Проект состоит из учебного агента без фреймворка и отдельного веб-приложения
«Рядом» на Google ADK. Рабочая директория учебных команд — `practice/`,
веб-приложения — `practice/mvp/`. В каждой части собственные зависимости и lock-файл.

- [Требования задания](assignment.md).
- [Учебный агент: установка, запуск, A/B и диагностика](practice/README.md).
- [Веб-MVP: Docker, чат, контекст и смысловой поиск](practice/mvp/README.md).
- [Учебный отчёт и три неудачные траектории](practice/report.md).

## Состав

| Путь | Что содержит |
|---|---|
| `practice/agent_loop.py` | Пять инструментов и ограниченный цикл модель → инструмент → наблюдение |
| `practice/answer_schema.py` | Типизированный JSON-контракт финального ответа |
| `practice/check.py` | Десять задач, независимая проверка фактов и метрики |
| `practice/ab_report.py` | Анализ A/B описаний без обращения к модели |
| `practice/failures.py` | Ограниченный поиск диагностических неудач |
| `practice/runs/` | Небольшие журналы, подтверждающие опубликованные результаты |
| `practice/tests/` | Автономные проверки учебной части |
| `practice/poi.sqlite`, `practice/data/` | База и исходный снимок OpenStreetMap |
| `practice/mvp/` | Отдельное веб-приложение, миграции, контейнеры и тесты |

Собственный цикл учебного агента не заменён ADK: это разные реализации
для разных требований. Их метрики и журналы оцениваются отдельно.

Данные описывают снимок OpenStreetMap, а не актуальные меню заведений.
Внешний провайдер модели выбирается через локальную конфигурацию;
ключи доступа в репозиторий не входят.
