# Рядом — локальная справочная по Ростову-на-Дону

Python 3.12, Google ADK, FastAPI, PostgreSQL 17/pgvector, локальные CPU embeddings
multilingual-e5-small. Интерфейс без Node и внешних ресурсов. Исходный учебный
цикл в родительском каталоге сохранён отдельно.

## Запуск в Docker

Нужны Docker Desktop с Linux containers, Compose 2.30+ и uv/Python 3.12
для однократного создания каталога и случайного пароля БД. Команды — из `mvp/`.
Для размещения кэша и временных файлов рядом с проектом настройте текущую
PowerShell-сессию. Окружение MVP отделено от учебного окружения:

```powershell
$practice = (Resolve-Path '..').Path
$env:UV_CACHE_DIR = Join-Path $practice '.cache/uv'
$env:UV_PYTHON_INSTALL_DIR = Join-Path $practice '.cache/python'
$env:UV_PROJECT_ENVIRONMENT = Join-Path (Get-Location).Path '.venv'
$env:TMP = Join-Path $practice '.cache/tmp'
$env:TEMP = $env:TMP
New-Item -ItemType Directory -Path $env:TMP -Force | Out-Null
uv run --locked python -m app.cli prepare
```

Создайте свой `.env` по [.env.example](.env.example): OPENAI_API_KEY, MODEL,
OPENAI_BASE_URL. Значения вводите самостоятельно; шаблон содержит только
плейсхолдеры. Базовый URL — без `/chat/completions`. Используется существующий
OpenRouter-провайдер; для бесплатной модели сохраняйте суффикс `:free`.
Файл конфигурации не входит в образ. Случайный пароль БД создаётся приложением
в `../private/mvp/app/db_password`, его не нужно просматривать или вводить вручную.

После подготовки конфигурации запуск одной командой:

```powershell
docker compose up --build -d --wait
```

Откройте [localhost:8000](http://localhost:8000), создайте аккаунт и задайте вопрос.
Смысловой индекс готовится в фоне; состояние видно над диалогом. Первый запуск
скачивает публичные зависимости и локальную модель, поэтому занимает больше времени.
`--wait` подтверждает доступность веб-сервиса, готовность индекса проверяется в UI.

Чтобы использовать уже имеющийся `.env` без копирования, задайте в текущей
PowerShell-сессии путь к нему, затем выполните ту же команду запуска:

```powershell
$env:MVP_ENV_FILE = (Resolve-Path '../../../.env').Path
```

В опубликованной структуре этот пример указывает на `.env` в корне репозитория.
Если настройки находятся в другом месте, укажите свой путь. Не выводите
содержимое файла или `docker compose config`.
Переменные окружения Compose читает опосредованно, приложение не показывает их значения.

```powershell
docker compose ps
docker compose stop
docker compose start --wait
```

PostgreSQL не публикует порт. Сайт доступен только через loopback компьютера.
Контейнеры используют bind mounts внутри родительской папки `practice/`:
`private/mvp/postgres` — БД, `private/mvp/app` — состояние/локальный секрет,
`.cache/models` — веса. `poi.sqlite` подключена только для чтения. Остановка
и пересоздание контейнеров сохраняют данные. Удаление каталогов данных не требуется.

## Как пользоваться

- «Сколько всего банков в городе?» — точный подсчёт по SQLite.
- «Хочу пельмени, найди похожие заведения» — сходство названий и кухонь OSM.
- «Расскажи о первом найденном месте» — карточка из предыдущего результата.
- «Ближайшая аптека к 47.23, 39.70», затем «А банк к тем же координатам?» — контекст.

SSE показывает очередь, шаг агента, вызов/результат инструмента и проверку
ответа. Приватные рассуждения модели не показываются. Разрыв SSE не запускает
модель заново: сохраняются id событий; после перезагрузки восстанавливается
история и активный запрос. Кнопка «Остановить» отменяет текущую задачу.
Одинаковый request_key не создаёт второй запрос.

Вход — логин из 3–32 латинских букв/цифр/`_`, пароль 12–128 символов.
Пароли хешируются Argon2id; сессии непрозрачные, в БД хранятся только хеши
токенов. Cookie HttpOnly, SameSite=Lax; для изменений проверяется CSRF.
История, ADK-сессии и SSE доступны только владельцу. Сессия действует 24 часа;
выход отзывает её. В MVP нет восстановления пароля и публичного размещения с TLS.

Один процесс Uvicorn обслуживает до пяти пользователей в очереди/работе,
три активных запуска модели и один незавершённый запрос на пользователя.
Лимиты вопроса: 6 обращений к модели, 20 вызовов инструментов, 90 секунд;
таймаут провайдера 30 секунд, автоматические retry выключены. Два повторных
неверных вызова или два сбоя источника прекращают цикл раньше.
Контекст обрезается по целым пользовательским ходам (до 8, до 64000 символов),
вызов инструмента и его результат остаются вместе. Последние id и координаты
сохраняются отдельно. После перезапуска незавершённые задачи получают interrupted,
автоматических платных или повторных запросов нет.

## Семантический поиск

604 restaurant/cafe/fast_food из неизменной SQLite. Документ содержит название,
бренд, вид и теги кухни с переводом. Префиксы E5 `passage:`/`query:`, нормализация,
384 измерения, cosine distance в pgvector; максимум 10 карточек. Порог 0.84,
небольшой бонус точному совпадению названия, необязательный фильтр улицы.
Фраза про пельмени расширяется до связанных русской/домашней кухонь.
В источнике нет прямого упоминания пельменей и нет меню: результат означает
смысловую близость, а не наличие блюда. Часы/адреса относятся к снимку OSM.

Модель закреплена revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`.
Версия индекса зависит от SHA-256 SQLite, словаря и преобразования документов,
идентификатора/revision модели. Повторный запуск не дублирует текущую версию;
новая становится активной только после полной успешной индексации.
Старая версия сохраняется при сбое. При обновлении модели пересмотрите порог.

```powershell
docker compose exec -T app python -m app.cli index
docker compose exec -T app python -m app.cli evaluate-search
```

Оценка не вызывает LLM; сохраняет `private/mvp/app/semantic-evaluation.json`.
На фиксированных 20 примерах: Hit@5 по тегу кухни 14/15 = 93.3%, буквальный
поиск по названию/исходным тегам 3/15 = 20%; пять посторонних запросов — пусто.
Для «чашки кофе» топ-5 не содержит ожидаемого тега coffee_shop. Порог подобран
на этом же наборе: это калибровка, не независимая оценка обобщения.

## Проверки без внешней модели

Из `mvp/`, после настройки TMP/кэшей командами выше:

```powershell
uv sync --locked
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path $practice '.cache/playwright'
uv run --locked python -m playwright install chromium
uv run --locked python -B -m pytest -p pytest_asyncio.plugin --basetemp ('../.cache/mvp-tests-' + [guid]::NewGuid().ToString('N'))
```

Для basetemp каждый раз выбирайте новый каталог. Эти тесты используют фиктивные модели,
конфигурацию и пароли, SQLite-фикстуры и локальный браузер; внешняя LLM не вызывается.
На Windows тестам нужен локальный loopback для event loop и браузерного сервера.
Скриншоты тестового UI создаются в `../private/mvp/screenshots`.

Проверены: хеширование/сессии/CSRF, изоляция двух пользователей, отмена,
идемпотентность, SSE replay, пять пользователей/три активных запуска,
контекст с парами tool call/result, лимиты ADK и проверка фактов ответа,
версионирование индекса, браузерная регистрация/вопрос/история/выход и ширина 390 px.
Отдельно проверены реальные pgvector, Docker persistence и 5 сквозных вопросов
с текущей бесплатной моделью. Повторяемость ответов внешнего сервиса не гарантируется.

Учебные 10×3 и A/B выполняются из родительского каталога по его README.
Их журналы и метрики не смешиваются с проверками MVP. Полные служебные отчёты,
кэши, секреты, веса и runtime data исключены из Git.
