# Задание 1. Инструменты, цикл и A/B описаний

Модель: `deepseek/deepseek-v4.1-flash@provider=deepinfra/fp8` через `polza.ai/api/v1`.
База: Ростов-на-Дону, 8860 мест OpenStreetMap (ODbL), 922 пункта выдачи.

## Метрики прогона (10 задач × 3 прогона)

| Метрика | full | short |
|---|---|---|
| pass@1 | 1.0 | 1.0 |
| pass^3 | 1.0 | 1.0 |
| средние токены (вход / выход) | 2810 / 131 | 1779 / 138 |
| среднее число шагов | 2.1 | 2.1 |
| средняя стоимость задачи | 0.126 ₽ | 0.086 ₽ |

Все десять задач решаются с первой попытки в обоих вариантах описаний.

## A/B описаний

Два набора описаний одних и тех же пяти инструментов: «короткие» (одна фраза) и
«полные» (что делает / когда звать / когда НЕ звать / единицы / пример).

| Вариант | верный инструмент и аргументы | 95% интервал Вильсона | входных токенов на прогон |
|---|---|---|---|
| short | 30 / 30 = 1.000 | [0.887, 1.000] | 1779 |
| full | 30 / 30 = 1.000 | [0.887, 1.000] | 2810 |

Вывод: на этих десяти задачах варианты неразличимы по точности — оба дают 30/30.
Полные описания стоят в среднем на ~1030 входных токенов дороже на прогон и не
окупаются приростом точности. Для этой модели и этого набора задач короткие
описания достаточны; полные имеет смысл держать для более сложных или двусмысленных
инструментов, где одного названия недостаточно, чтобы отличить их друг от друга.

## Разбор ошибок

Штатные 10 задач пройдены без провалов, поэтому три неудачные траектории получены
намеренно (скрипт `failures.py`) — по одной на класс ошибки.

1. Ошибка среды. Инструмент бросил `ZeroDivisionError`. Цикл не упал: исключение
   превратилось в наблюдение `ОШИБКА: ZeroDivisionError: division by zero`, модель
   получила его и корректно вышла из ситуации, не повторив вызов.

2. Зацикливание. Упрямый инструмент, который на любой запрос просит уточнить фильтр.
   Модель звала его до исчерпания лимита (6 вызовов), прогон остановлен
   предохранителем (`stopped_by_limit=True`), финального ответа нет.

3. Ложное «готово». Вопрос «где лучше открыть кофейню» не решается ни одним из
   инструментов. Модель вызвала несколько инструментов, но в финальном ответе
   выдала рекомендации и детали, которые не сверяются с базой (аренда, трафик,
   «лучшее место») — уверенный ответ без фактической опоры.

## Состав репозитория

- `agent_loop.py` — агент без фреймворка: 5 инструментов, цикл, лимит шагов,
  ошибки как наблюдения, журнал JSONL, счётчики токенов и стоимости.
- `check.py` — прогон 10 задач, метрики pass@1 / pass^k, средние токены, стоимость, шаги.
- `ab_report.py` — A/B описаний: доля верного выбора и интервал Вильсона.
- `failures.py` — генератор трёх неудачных траекторий для разбора ошибок.
- `runs/` — журналы всех прогонов в JSONL.
- `sdk_tasks.py`, `poi.sqlite`, `data/` — данные и функции базы (даны курсом).

## Запуск на чистой машине

```bash
uv sync
uv run python check.py --n 3
```

Требует `.env` с `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `MODEL` (шаблон — `.env.example`).
