# Учебный агент: пять инструментов и цикл без фреймворка

Python 3.12, uv, OpenAI-совместимый Chat Completions API и SQLite.
Агент отвечает на вопросы о 8860 местах Ростова-на-Дону из снимка OpenStreetMap.
Пять инструментов: подсчёт, поиск, ближайшее место, бренды и карточка объекта.
Цикл реализован вручную; веб-приложение на Google ADK находится отдельно
в [mvp/README.md](mvp/README.md).

## Установка и запуск

Все команды выполняются из этой папки: `week2/practice`.
Нужны Python 3.12 и uv. Если интерпретатора нет, установите его через uv:

```powershell
uv python install 3.12
```

Создайте локальный `.env` по [.env.example](.env.example), самостоятельно
заполните `OPENAI_API_KEY`, `MODEL` и `OPENAI_BASE_URL`.
Базовый URL задаётся без завершающего `/chat/completions`.
Пример использует OpenRouter; доступность и квоту модели проверяйте у провайдера.
Приложение также поддерживает конфигурацию в корне репозитория.
Действующие ключи не нужно вставлять в команды, код или журналы.

После подготовки настроек десять задач по три раза запускаются одной командой;
uv создаёт окружение и устанавливает зависимости по `uv.lock`:

```powershell
uv run --locked python check.py --n 3
```

Команда обращается к внешней модели: до 30 попыток × 6 шагов = 180 запросов.
Повторы клиента отключены. Даже бесплатная модель может иметь ограничения квоты.
Для одного собственного вопроса:

```powershell
uv run --locked python agent_loop.py "Сколько аптек в Ростове?"
```

## A/B описаний

Один эксперимент с короткими и полными описаниями одних и тех же инструментов:

```powershell
uv run --locked python check.py --n 3 --variant both --experiment-id ab-next-01
uv run --locked python ab_report.py --experiment-id ab-next-01
```

Выбирайте новый идентификатор каждого эксперимента. Получаются 60 независимых
попыток с новой историей, максимум 360 запросов. Схемы, исполнители и контракт
финального ответа одинаковы; меняются описания. Ошибка API сохраняет частичную
траекторию и останавливает эксперимент. Неполный набор не получает итоговую оценку.

Пересчёт опубликованного A/B без API:

```powershell
uv run --locked python ab_report.py --experiment-id live-ab-20261021-02
```

Результат 21 октября 2026 года: 30/30 успешных попыток и 30/30 правильных первых
вызовов для каждого варианта; 95% интервал Вильсона [0.8865; 1.0000].
Короткие описания — 3359.17 токена на попытку, полные — 4131.90 (+23%).
Дополнительные токены не дали прироста точности на этом небольшом наборе.
[Учебный отчёт](report.md) содержит таблицы и ограничения вывода.

Исторический анализ прежнего свободного формата также доступен без API:

```powershell
uv run --locked python ab_report.py --legacy
```

Он не оценивает текущий контракт и модель.

## Метрики и проверка фактов

- `pass@1` — доля задач, решённых первой попыткой.
- `pass^3` — доля задач, где успешны все три попытки.
- `pass@3` — дополнительная метрика: успешна хотя бы одна из трёх попыток.
- Расход — входные, выходные и суммарные токены из `usage`; при отсутствии
  счётчиков расход неизвестен, а не равен нулю. Валютная стоимость не вычисляется.
- A/B — правильность первого инструмента и существенных аргументов, включая
  координаты и `only_24_7`; интервал Вильсона и токены на верный выбор.
  Маленький набор не позволяет делать вывод о статистической значимости разницы.

Финальный ответ — JSON типа `count`, `places`, `nearest`, `brands`, `details`
или `unavailable`; схемы находятся в [answer_schema.py](answer_schema.py).
Факты сравниваются с SQLite. Некорректный JSON, неверные аргументы и ошибки
инструмента возвращаются агенту как наблюдения в пределах общего лимита.

## Диагностические неудачи

Реальные подтверждающие журналы сохранены в `runs/`; разбор трёх траекторий —
в [report.md](report.md). Два случая получены контролируемым отказом хранилища,
третий — провоцирующим промптом с неверными аргументами существующего инструмента.
Искать повторные вызовы неизвестного инструмента пробовали девять раз:
искомое поведение не воспроизвелось. Это не доказывает невозможность ошибки.

Команды нового поиска обращаются к внешней модели:

```powershell
uv run --locked python failures.py --experiment-id failure-search-next-01
uv run --locked python failures.py --unknown-tool-search --experiment-id unknown-tool-next-01
```

Первая команда выполняет до 18 штатных попыток и, если нужно, до трёх явно
помеченных `fault_injected=true` отказов хранилища: максимум 126 запросов.
Вторая — до девяти попыток по шесть шагов: максимум 54 запроса.
Сценарий не гарантирует неудачу. Ошибки окружения и корректные отказы отделяются
от дефектов модели; диагностика не входит в метрики десяти задач и A/B.
`check_provider.py` также вызывает провайдера и не является автономным тестом.

## Тесты без внешней модели

```powershell
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD = '1'
uv run --locked python -B -m pytest --basetemp ('.cache/pytest-' + [guid]::NewGuid().ToString('N'))
```

Тесты используют фиктивные ответы, блокируют сеть и не загружают рабочие ключи.
Проверяют цикл, схемы, лимиты, санитизацию, независимую оценку, A/B,
диагностику и безопасную сборку базы. При завершении реализации прошли 75 тестов;
текущее выполнение следует оценивать по результату команды.

## Файлы и данные

- `agent_loop.py` — инструменты, схемы, ограниченный цикл, JSONL и токены.
- `check.py` — десять задач и проверяемые метрики.
- `ab_report.py` — анализ одного выбранного A/B либо исторического журнала.
- `failures.py` — поиск диагностических неудач с независимыми эталонами.
- `sdk_tasks.py` — исходная учебная обвязка над SQLite.
- `poi.sqlite`, `data/rostov_poi.json` — готовая база и публичный снимок OSM.
- `pyproject.toml`, `uv.lock` — прямые и транзитивные зависимости;
  `requirements.txt` содержит прямые зависимости времени выполнения.
- `mvp/` — отдельное приложение, окружение и тесты; его метрики не смешиваются с учебными.

Обычный запуск не пересобирает данные. `make_poi_dataset.py` пересоздаёт базу;
`--refresh` дополнительно загружает данные OSM. Эти команды не нужны для проверки
задания и изменяют данные. SQLite подключается инструментами только для чтения.

Новые JSONL исключены из Git по умолчанию; разрешён только небольшой набор
проверенных журналов. В них нет значений рабочей конфигурации: сохраняются
фингерпринты, счётчики и санитизированные события. Распознаваемые ключи,
контакты и URL маскируются. Не вводите приватные данные в вопросы.
